Le Code Caché (JSON-LD)

Chacune de vos 500 pages doit contenir ce script caché. C'est ce qui dit à Google : "Ceci est un service LOCAL spécifique à CETTE ville". Sans ça, vous n'êtes qu'une page dupliquée de plus.

Pourquoi c'est vital ?

  • Lie le Service à la Localisation.
  • Active les "Rich Snippets" (étoiles, prix).
  • Aide l'algorithme à comprendre la pertinence géographique.
application/ld+json Généré Dynamiquement
{
  "@context": "https://schema.org",
  "@type": "Service",
  "serviceType": "Dépannage Toiture",
  "areaServed": {
    "@type": "City",
    "name": "Paris",
    "postalCode": "75000"
  },
  "provider": {
    "@type": "LocalBusiness",
    "name": "Lead-Dexing Pro"
  }
}
