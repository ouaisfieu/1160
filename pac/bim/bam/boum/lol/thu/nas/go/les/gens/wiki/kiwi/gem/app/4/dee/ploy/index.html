4. Recommandations

  • Désactiver le listing des répertoires : Modifier la configuration Nginx (autoindex off) pour empêcher l'exploration libre.
  • Renforcer les Headers : Implémenter HSTS et Content-Security-Policy pour mitiger les attaques XSS et MITM.
  • Authentification : Protéger les zones /backup et /private via Basic Auth ou OAuth.
